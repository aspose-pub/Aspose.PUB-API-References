该 **Aspose.Pub** 命名空间提供描述 PUB 对象的类。

## 类

| 类 | 描述 |
| --- | --- |
| [BaseStyle](./basestyle/) | 声明 PUB 样式的基础功能 |
| [BuildVersionInfo](./buildversioninfo/) | 此类提供有关当前产品构建的信息。 |
| [DocSummaryInfo](./docsummaryinfo/) | 文档摘要信息 |
| [Document](./document/) | 表示 PUB 文档，保存所有字段和相关值 |
| [FolderFontSource](./folderfontsource/) | 表示包含字体文件的文件夹。 |
| [FontSource](./fontsource/) | 表示字体来源的基类。 |
| [FontSubstitution](./fontsubstitution/) | 表示基于字体名称的字体替代策略类。 |
| [License](./license/) | 提供对组件授权的方法。 |
| [MetaInfo](./metainfo/) | 摘要信息对象的基类 |
| [Metered](./metered/) | 提供设置计量密钥的方法。 |
| [PackageDocumentCollection](./packagedocumentcollection/) | 表示用于包转换的 Publisher 文档集合。 |
| [PackageDocumentItem](./packagedocumentitem/) | 用于包转换的 Publisher 文档引用的基类。提供用于指定转换后文档输出来源的字段——[`OutputFileName`](../aspose.pub/packagedocumentitem/outputfilename/) 用于磁盘文件，[`OutputStream`](../aspose.pub/packagedocumentitem/outputstream/) 用于流。此外，还提供转换设置。 |
| [PackageFileItem](./packagefileitem/) | 设计用于在包转换中通过文件引用 Publisher 文档。 |
| [PackageStreamItem](./packagestreamitem/) | 设计用于在包转换中通过流引用 Publisher 文档。 |
| [ParagraphStyle](./paragraphstyle/) | 此类描述 PUB 段落的样式 |
| [PubFactory](./pubfactory/) | PUB 对象的工厂 |
| [PubToPdfConversionOptions](./pubtopdfconversionoptions/) | 导出为 PDF 格式的选项 |
| [SummaryInfo](./summaryinfo/) | 摘要信息 |
| [TextGroup](./textgroup/) | 文本组 |
| [TextParagraph](./textparagraph/) | 表示 PUB 文本段落 |
| [TextStyle](./textstyle/) | 描述 PUB 文本样式 |
## 接口

| 接口 | 描述 |
| --- | --- |
| [IPdfConverter](./ipdfconverter/) | 声明将 PUB 文档转换为 PDF 文档的功能 |
| [IPubConverter](./ipubconverter/) | 声明将 PUB 文档转换为指定格式的功能 |
| [IPubPackageConverter](./ipubpackageconverter/) | 声明将多个 Publisher 文档转换为指定格式的功能。 |
| [IPubParser](./ipubparser/) | 声明解析 publisher 文件并返回 [`Document`](../aspose.pub/document/) 对象作为解析结果。 |

| [PubDocumentType](./pubdocumenttype/) | 表示文档的存储类型。 |

| [SuperscriptType](./superscripttype/) | 上标类型 |
