## FontSubstitution.ReplaceAlways property

指定是否始终替换字体。如果设置为 false，则仅在目标电脑上未找到由 [`OriginalFontName`](../originalfontname/) 参数指定的字体名称时才会替换字体。

```csharp
public bool ReplaceAlways { get; }
```
