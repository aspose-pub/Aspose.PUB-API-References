## Point::Add method


Belirtilen [Size](../../size/) nesnesinin genişlik ve yükseklik değerlerini, belirtilen [Point](../) nesnesinin X ve Y koordinat değerlerine karşılık gelecek şekilde ekler.

```cpp
static Point System::Drawing::Point::Add(const Point &point, const Size &size)
```


| Parametre | Tür | Açıklama |
| --- | --- | --- |
| nokta | const Point\& | Çevrilecek nokta |
| size | const Size\& | Belirtilen [Size](../../size/) nesnesi, **point** koordinat değerlerine eklenecek değerleri belirtir. |

### ReturnValue

Yeni bir [Point](../) nesnesi; X koordinat değeri **point**'in X koordinat değeri ile **size**'in genişlik değerinin toplamına, Y koordinat değeri ise **point**'in Y koordinat değeri ile **size**'in yükseklik değerinin toplamına eşittir.
