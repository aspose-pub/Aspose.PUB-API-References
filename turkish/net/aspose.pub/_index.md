| [FontSource](./fontsource/) | Yazı tipi kaynağı için temel bir sınıfı temsil eder. |

| [MetaInfo](./metainfo/) | Özet bilgi nesneleri için temel sınıf |

| [PackageDocumentCollection](./packagedocumentcollection/) | Paket dönüşümü için Publisher belgelerinin koleksiyonunu temsil eder. |
| [PackageDocumentItem](./packagedocumentitem/) | Paket dönüşümlerinde kullanılmak üzere Publisher belge referansları için temel sınıf. Dönüştürülen belge için çıkış kaynağını belirtmek üzere alanlar sağlar - [`OutputFileName`](../aspose.pub/packagedocumentitem/outputfilename/) bir disk dosyası için ve [`OutputStream`](../aspose.pub/packagedocumentitem/outputstream/) akış için. Ayrıca dönüşüm ayarlarını da sağlar. |
| [PackageFileItem](./packagefileitem/) | Paket dönüşümlerinde dosya aracılığıyla bir Publisher belgesine referans vermek için tasarlanmıştır. |
| [PackageStreamItem](./packagestreamitem/) | Paket dönüşümlerinde akış aracılığıyla bir Publisher belgesine referans vermek için tasarlanmıştır. |
| [ParagraphStyle](./paragraphstyle/) | Bu sınıf, PUB paragrafının stilini tanımlar |
| [PubFactory](./pubfactory/) | PUB nesneleri için fabrika |
| [PubToPdfConversionOptions](./pubtopdfconversionoptions/) | PDF formatına dışa aktarma seçenekleri |
| [SummaryInfo](./summaryinfo/) | Özet bilgisi |
| [TextGroup](./textgroup/) | Metin grubu |

| [TextStyle](./textstyle/) | PUB metin stilini tanımlar |
