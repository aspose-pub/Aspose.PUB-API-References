## FontSubstitution.ReplaceAlways property

Specifica se i caratteri devono essere sempre sostituiti. Se impostata su false, i caratteri vengono sostituiti solo quando il carattere con il nome specificato dal parametro [`OriginalFontName`](../originalfontname/) non è trovato sul PC di destinazione.

```csharp
public bool ReplaceAlways { get; }
```
