## SummaryInfo.DocSecurity property

Il Document security ID Document security ID è un intero con segno a 32 bit che rappresenta un insieme di flag di controllo accessi suggeriti dall'applicazione con i seguenti valori: 0x00000001: Protetto da password 0x00000002: Solo lettura consigliato 0x00000004: Solo lettura imposto 0x00000008: Bloccato per annotazioni
