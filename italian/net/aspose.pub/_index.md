Lo spazio dei nomi **Aspose.Pub** fornisce classi che descrivono gli oggetti PUB.

## Classi

| Classe | Descrizione |
| --- | --- |
| [BaseStyle](./basestyle/) | Dichiara la funzionalità di base per gli stili PUB |
| [BuildVersionInfo](./buildversioninfo/) | Questa classe fornisce informazioni sulla build corrente del prodotto. |
| [DocSummaryInfo](./docsummaryinfo/) | Informazioni di riepilogo del documento |
| [Document](./document/) | Rappresenta un documento PUB, contiene tutti i campi e i valori pertinenti |
| [FolderFontSource](./folderfontsource/) | Rappresenta la cartella che contiene i file dei font. |
| [FontSource](./fontsource/) | Rappresenta una classe base per la sorgente dei font. |
| [FontSubstitution](./fontsubstitution/) | Rappresenta una classe per una strategia di sostituzione dei font basata sul nome del font. |
| [License](./license/) | Fornisce metodi per licenziare il componente. |
| [MetaInfo](./metainfo/) | Classe base per gli oggetti di informazioni di riepilogo |
| [Metered](./metered/) | Fornisce metodi per impostare la chiave a consumo. |
| [PackageDocumentCollection](./packagedocumentcollection/) | Rappresenta una raccolta di documenti Publisher per la conversione di pacchetti. |
| [PackageDocumentItem](./packagedocumentitem/) | Classe base per i riferimenti a documenti Publisher da utilizzare nelle conversioni di pacchetti. Fornisce campi per specificare la sorgente di output per il documento convertito - [`OutputFileName`](../aspose.pub/packagedocumentitem/outputfilename/) per un file su disco e [`OutputStream`](../aspose.pub/packagedocumentitem/outputstream/) per lo stream. Fornisce inoltre le impostazioni di conversione. |
| [PackageFileItem](./packagefileitem/) | Progettato per fare riferimento a un documento Publisher tramite file nelle conversioni di pacchetto. |
| [PackageStreamItem](./packagestreamitem/) | Progettato per fare riferimento a un documento Publisher tramite stream nelle conversioni di pacchetto. |
| [ParagraphStyle](./paragraphstyle/) | Questa classe descrive lo stile del paragrafo PUB |
| [PubFactory](./pubfactory/) | Factory per oggetti PUB |
| [PubToPdfConversionOptions](./pubtopdfconversionoptions/) | Opzioni per l'esportazione in formato PDF |
| [SummaryInfo](./summaryinfo/) | Informazioni di riepilogo |
| [TextGroup](./textgroup/) | Gruppo di testo |
| [TextParagraph](./textparagraph/) | Rappresenta il paragrafo di testo PUB |
| [TextStyle](./textstyle/) | Descrive lo stile del testo PUB |
## Interfacce

| Interfaccia | Descrizione |
| --- | --- |
| [IPdfConverter](./ipdfconverter/) | Dichiara la funzionalità per convertire un documento PUB in un documento PDF |
| [IPubConverter](./ipubconverter/) | Dichiara la funzionalità per convertire un documento PUB nel formato specificato |
| [IPubPackageConverter](./ipubpackageconverter/) | Dichiara la funzionalità per convertire più documenti Publisher in un formato specificato. |
| [IPubParser](./ipubparser/) | Dichiara la funzionalità che analizza il file publisher e restituisce l'oggetto [`Document`](../aspose.pub/document/) come risultato dell'analisi. |
