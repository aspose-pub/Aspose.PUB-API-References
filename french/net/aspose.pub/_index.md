L'espace de noms **Aspose.Pub** fournit des classes décrivant les objets PUB.

## Classes

| Classe | Description |
| --- | --- |
| [BaseStyle](./basestyle/) | Déclare la fonctionnalité de base pour les styles PUB |
| [BuildVersionInfo](./buildversioninfo/) | Cette classe fournit des informations sur la version actuelle du produit. |
| [DocSummaryInfo](./docsummaryinfo/) | Informations récapitulatives du document |
| [Document](./document/) | Représente un document PUB, contient tous les champs et les valeurs pertinentes |
| [FolderFontSource](./folderfontsource/) | Représente le dossier qui contient les fichiers de polices. |
| [FontSource](./fontsource/) | Représente une classe de base pour la source de police. |
| [FontSubstitution](./fontsubstitution/) | Représente une classe pour une stratégie de substitution de police basée sur le nom de la police. |
| [License](./license/) | Fournit des méthodes pour licencier le composant. |
| [MetaInfo](./metainfo/) | Classe de base pour les objets d'informations récapitulatives |
| [Metered](./metered/) | Fournit des méthodes pour définir la clé mesurée. |
| [PackageDocumentCollection](./packagedocumentcollection/) | Représente une collection de documents Publisher pour la conversion de paquet. |
| [PackageDocumentItem](./packagedocumentitem/) | Classe de base pour les références de documents Publisher utilisées dans les conversions de paquets. Fournit des champs pour spécifier la source de sortie du document converti - [`OutputFileName`](../aspose.pub/packagedocumentitem/outputfilename/) pour un fichier disque et [`OutputStream`](../aspose.pub/packagedocumentitem/outputstream/) pour un flux. Fournit également les paramètres de conversion. |
| [PackageFileItem](./packagefileitem/) | Conçu pour référencer un document Publisher via un fichier lors des conversions de package. |
| [PackageStreamItem](./packagestreamitem/) | Conçu pour référencer un document Publisher via un flux lors des conversions de package. |
| [ParagraphStyle](./paragraphstyle/) | Cette classe décrit le style d'un paragraphe PUB |
| [PubFactory](./pubfactory/) | Fabrique d'objets PUB |
| [PubToPdfConversionOptions](./pubtopdfconversionoptions/) | Options d'exportation au format PDF |
| [SummaryInfo](./summaryinfo/) | Informations de résumé |
| [TextGroup](./textgroup/) | Groupe de texte |
| [TextParagraph](./textparagraph/) | Représente le paragraphe de texte PUB |
| [TextStyle](./textstyle/) | Décrit le style de texte PUB |
## Interfaces

| Interface | Description |
| --- | --- |
| [IPdfConverter](./ipdfconverter/) | Déclare la fonctionnalité de convertir un document PUB en document PDF |
| [IPubConverter](./ipubconverter/) | Déclare la fonctionnalité de convertir un document PUB dans le format spécifié |
| [IPubPackageConverter](./ipubpackageconverter/) | Déclare la fonctionnalité de conversion de plusieurs documents Publisher vers un format spécifié. |
| [IPubParser](./ipubparser/) | Déclare la fonctionnalité qui analyse le fichier publisher et renvoie l'objet [`Document`](../aspose.pub/document/) en résultat de l'analyse. |
