## PackageDocumentItem class

Classe de base pour les références de documents Publisher utilisées dans les conversions de paquet. Fournit des champs pour spécifier la source de sortie du document converti - [`OutputFileName`](./outputfilename/) pour un fichier disque et [`OutputStream`](./outputstream/) pour un flux. Fournit également les paramètres de conversion.
