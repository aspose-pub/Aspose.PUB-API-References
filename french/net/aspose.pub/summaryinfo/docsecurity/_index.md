## SummaryInfo.DocSecurity property

L'ID de sécurité du document Document security ID est un entier signé de 32 bits représentant un ensemble de drapeaux de contrôle d'accès suggérés par l'application avec les valeurs suivantes : 0x00000001 : protégé par mot de passe 0x00000002 : lecture seule recommandée 0x00000004 : lecture seule appliquée 0x00000008 : verrouillé pour les annotations
