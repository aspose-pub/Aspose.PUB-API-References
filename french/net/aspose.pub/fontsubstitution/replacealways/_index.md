## FontSubstitution.ReplaceAlways property

Spécifie si les polices doivent toujours être remplacées. Si elle est définie sur false, les polices sont substituées uniquement lorsque la police dont le nom est spécifié par le paramètre [`OriginalFontName`](../originalfontname/) n'est pas trouvée sur le PC de destination.

```csharp
public bool ReplaceAlways { get; }
```
