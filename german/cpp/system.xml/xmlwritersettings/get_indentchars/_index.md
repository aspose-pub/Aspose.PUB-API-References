## XmlWriterSettings::get_IndentChars method


Gibt die Zeichenkette zurück, die beim Einrücken verwendet wird. Diese Einstellung wird verwendet, wenn der [XmlWriterSettings::set_Indent](../set_indent/)‑Wert auf **true** gesetzt ist.

```cpp
String System::Xml::XmlWriterSettings::get_IndentChars()
```


### ReturnValue

Die Zeichenkette, die beim Einrücken verwendet wird. Sie kann auf jeden Zeichenkettenwert gesetzt werden. Um jedoch gültiges XML zu gewährleisten, sollten Sie nur gültige Leerzeichen‑Zeichen angeben, wie z. B. Leerzeichen, Tabulatoren, Wagenrückläufe oder Zeilenumbrüche. Der Standardwert sind zwei Leerzeichen.
