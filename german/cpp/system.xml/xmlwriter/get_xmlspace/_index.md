## XmlWriter::get_XmlSpace method


Wenn in einer abgeleiteten Klasse überschrieben, wird ein XmlSpace abgerufen, das den aktuellen **xml:space**‑Bereich darstellt.

```cpp
virtual System::Xml::XmlSpace System::Xml::XmlWriter::get_XmlSpace()
```


### ReturnValue

Ein XmlSpace, das den aktuellen **xml:space**‑Geltungsbereich darstellt.

|||
|-|-|
| Wert | Bedeutung |
| None | Dies ist die Vorgabe, wenn kein xml:space‑Geltungsbereich existiert. |
| Default | Der aktuelle Geltungsbereich ist xml:space=\"default\". |
| Preserve | Der aktuelle Geltungsbereich ist xml:space=\"preserve\". |
