## XmlWriter::LookupPrefix method


Wenn in einer abgeleiteten Klasse überschrieben, wird das nächstgelegene Präfix zurückgegeben, das im aktuellen Namensraum‑Bereich für die Namensraum‑URI definiert ist.

```cpp
virtual String System::Xml::XmlWriter::LookupPrefix(String ns)=0
```


| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| ns | String | Die Namespace-URI, deren Präfix Sie finden möchten. |

### ReturnValue

Das passende Präfix oder **nullptr**, falls im aktuellen Geltungsbereich keine passende Namespace‑URI gefunden wird.
