## XmlNodeOrder enum


Beschreibt die Dokumentreihenfolge eines Knotens im Vergleich zu einem zweiten Knoten.

```cpp
enum class XmlNodeOrder
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Vorher | 0 | Der aktuelle Knoten dieses Navigators liegt vor dem aktuellen Knoten des übergebenen Navigators. |
| Nachher | 1 | Der aktuelle Knoten dieses Navigators liegt nach dem aktuellen Knoten des übergebenen Navigators. |
| Gleich | 2 | Die beiden Navigatoren befinden sich auf demselben Knoten. |
| Unbekannt | 3 | Die Knotenpositionen können in Dokumentreihenfolge relativ zueinander nicht bestimmt werden. Dies kann auftreten, wenn die beiden Knoten in unterschiedlichen Bäumen liegen. |
