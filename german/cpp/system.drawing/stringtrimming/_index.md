## StringTrimming enum


Gibt an, wie Zeichen aus einem String, der nicht in die Layoutform passt, abgeschnitten werden sollen.

```cpp
enum class StringTrimming
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| None | 0 | Kein Abschneiden. |
| Zeichen | 1 | Auf das nächste Zeichen zuschneiden. |
| Wort | 2 | Auf das nächste Wort zuschneiden. |
| EllipsisCharacter | 3 | Auf das nächste Zeichen zuschneiden und am Ende der Zeichenkette ein Auslassungszeichen einfügen. |
| EllipsisWord | 4 | Auf das nächste Wort zuschneiden und am Ende der Zeichenkette ein Auslassungszeichen einfügen. |
| EllipsisPath | 5 | Der Mittelteil wird aus gekürzten Zeilen entfernt und durch ein Auslassungszeichen ersetzt. So viel wie möglich vom letzten durch Schrägstriche getrennten Segment der Zeile beibehalten. |
