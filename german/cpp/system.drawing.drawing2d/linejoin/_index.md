## LineJoin enum


Gibt an, wie aufeinanderfolgende Linien oder Kurven verbunden werden.

```cpp
enum class LineJoin
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Miter | 0 | Mitered join, die je nach Länge des Gehrungswinkels, die das Gehrungsgrenzenlimit überschreitet, eine scharfe oder abgeschnittene Ecke erzeugt. |
| Bevel | 1 | Bevel join, die eine diagonale Ecke erzeugt. |
| Rund | 2 | Round join, die einen glatten kreisförmigen Bogen zwischen den Linien erzeugt. |
| MiterClipped | 3 | Mitered join, die je nach Länge des Gehrungswinkels, die das Gehrungsgrenzenlimit überschreitet, eine scharfe oder abgeschrägte Ecke erzeugt. |
