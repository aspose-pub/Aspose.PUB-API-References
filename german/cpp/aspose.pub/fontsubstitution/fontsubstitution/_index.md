

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| originalFontName | System::String | Originaler Schriftname. |
| substitutionFontName | System::String | Ersetzungs-Schriftname. |
| replaceAlways | bool | Gibt an, ob Schriften immer ersetzt werden sollen. Wenn es auf false gesetzt ist, werden Schriften nur dann ersetzt, wenn eine Schrift mit dem im Parameter [OriginalFontName](../) angegebenen Namen auf dem Ziel-PC nicht gefunden wird. Standardmäßig false. |
