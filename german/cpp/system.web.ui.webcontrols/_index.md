## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [DataGrid](./datagrid/) | Dummy-Klasse, die es ermöglicht, übersetzten Code mit [DataGrid](./datagrid/) Referenzen zu verlinken, jedoch nicht auszuführen. Enthält keine korrekt implementierten Mitglieder. Objekte dieser Klasse sollten nur über die Funktion [System::MakeObject()](../system/makeobject/) alloziert werden. Erstellen Sie niemals eine Instanz dieses Typs auf dem Stack oder mit dem Operator new, da dies zu Laufzeitfehlern und/oder Assertionsfehlern führt. Wickeln Sie diese Klasse immer in einen [System::SmartPtr](../system/smartptr/) Zeiger ein und verwenden Sie diesen Zeiger, um ihn als Argument an Funktionen zu übergeben. |
