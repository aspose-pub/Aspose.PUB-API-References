## DateTime::Subtract(DateTime) const method


Gibt eine Instanz der Klasse [TimeSpan](../../timespan/) zurück, die das Zeitintervall zwischen den von dem aktuellen und dem angegebenen Objekt dargestellten Datums- und Uhrzeitwerten repräsentiert.

```cpp
TimeSpan System::DateTime::Subtract(DateTime value) const
```


| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| value | DateTime | Eine Instanz der Klasse [DateTime](../), die ein Ende des zu berechnenden Intervalls markiert. |

### ReturnValue

Eine Instanz der Klasse [TimeSpan](../../timespan/), die das Zeitintervall zwischen den von dem aktuellen Objekt und **value** dargestellten Datums- und Uhrzeitwerten repräsentiert.
