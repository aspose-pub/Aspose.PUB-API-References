## DateTime::operator<=(DateTime) const method


Bestimmt, ob das aktuelle Objekt den Datums‑ und Zeitwert darstellt, der früher liegt oder dem von dem angegebenen [DateTime](../)-Objekt dargestellten Wert entspricht.

```cpp
bool System::DateTime::operator<=(DateTime other) const
```


| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| other | DateTime | Das [DateTime](../)-Objekt, mit dem das aktuelle Objekt verglichen werden soll |

### ReturnValue

Wahr, wenn der vom aktuellen Objekt dargestellte Datums- und Uhrzeitwert früher oder gleich dem von **other** dargestellten Wert ist, sonst – falsch
