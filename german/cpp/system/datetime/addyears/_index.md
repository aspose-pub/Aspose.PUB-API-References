```cpp
DateTime System::DateTime::AddYears(int value) const
```


| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| Wert | int | Die Anzahl der hinzuzufügenden Jahre; der Wert kann positiv oder negativ sein. |

### ReturnValue

Eine neue Instanz der [DateTime](../)-Klasse, die den Datum‑Uhrzeit‑Wert darstellt, der dem vom aktuellen Objekt dargestellten entspricht, jedoch mit dem Jahresanteil um **value** erhöht.
