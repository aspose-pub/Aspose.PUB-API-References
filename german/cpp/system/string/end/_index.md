## String::end method


Gibt einen Zeiger auf das Ende des tatsächlichen Zeichenpuffers zurück. Allokiert niemals etwas neu. Garantiert nicht, dass der Puffer nullterminiert ist.

```cpp
const UChar * System::String::end() const
```


### ReturnValue

Zeiger auf das erste Element nach dem tatsächlichen Zeichenkettenpuffer, nullterminiert oder nicht.
