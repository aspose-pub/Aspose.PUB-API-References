## ValueType class


Basisklasse für Werttypen, bei denen die Vererbung von [Object](../object/) aus Leistungsgründen abgeschnitten wird. Dieser Typ sollte auf dem Stack allokiert und an Funktionen per Wert oder per Referenz übergeben werden. Verwenden Sie niemals die [System::SmartPtr](../smartptr/) Klasse, um Objekte dieses Typs zu verwalten.

```cpp
class ValueType
```
