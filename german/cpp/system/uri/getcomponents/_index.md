## Uri::GetComponents method


Gibt die angegebenen Komponenten der vom aktuellen Objekt dargestellten URI zurück, wobei die angegebene Escape-Methode verwendet wird.

```cpp
String System::Uri::GetComponents(UriComponents components, UriFormat format) const
```


| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| Komponenten | UriComponents | Eine bitweise Kombination der UriComponents-Werte, die angibt, welche Teile der URI zurückgegeben werden sollen. |
| Format | UriFormat | Gibt an, wie die Sonderzeichen escaped werden. |

### ReturnValue

Die angeforderten Komponenten
