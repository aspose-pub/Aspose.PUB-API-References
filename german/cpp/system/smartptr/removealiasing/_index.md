## SmartPtr::RemoveAliasing method


Entfernt Aliasing (erstellt durch einen Alias-Konstruktor) vom Zeiger, stellt sicher, dass er (bei geteilten Zeigern) verwaltet oder (bei schwachen Zeigern) verfolgt, dasselbe Objekt, auf das er zeigt.

```cpp
SmartPtr_ System::SmartPtr<T>::RemoveAliasing() const
```


### ReturnValue

Der Zeiger auf dasselbe Objekt, auf das dieser Zeiger zeigt und der die Lebensdauer desselben Objekts überwacht.
