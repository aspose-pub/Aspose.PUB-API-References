## AuthenticationLevel enum


WebRequest-spezifische Authentifizierungsflags.

```cpp
enum class AuthenticationLevel
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| None | 0 | Für Client und Server ist keine Authentifizierung erforderlich. |
| MutualAuthRequested | 1 | Die Anfrage schlägt nicht fehl, wenn der Server nicht authentifiziert ist. |
| MutualAuthRequired | 2 | Die aktuelle Anwendung erhält 'IOException', wenn der Server nicht authentifiziert ist. |
