## FontSubstitution.ReplaceAlways property

Gibt an, ob Schriften immer ersetzt werden sollen. Ist sie auf false gesetzt, werden Schriften nur ersetzt, wenn eine Schrift mit dem im Parameter [`OriginalFontName`](../originalfontname/) angegebenen Namen auf dem Ziel-PC nicht gefunden wird.

```csharp
public bool ReplaceAlways { get; }
```
