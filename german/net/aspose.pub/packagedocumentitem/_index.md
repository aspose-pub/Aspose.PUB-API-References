## PackageDocumentItem class

Basisklasse für Publisher-Dokumentreferenzen zur Verwendung bei Paketkonvertierungen. Stellt Felder zum Festlegen der Ausgabeverbindung für das konvertierte Dokument bereit – [`OutputFileName`](./outputfilename/) für eine Datei auf dem Datenträger und [`OutputStream`](./outputstream/) für einen Stream. Außerdem werden Konvertierungseinstellungen bereitgestellt.
