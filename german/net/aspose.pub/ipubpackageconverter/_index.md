## IPubPackageConverter interface

Deklariert die Funktionalität zum Konvertieren mehrerer Publisher-Dokumente in ein angegebenes Format.

```csharp
public interface IPubPackageConverter
```

## Methoden

| Name | Beschreibung |
| --- | --- |
| [ConvertToFormat](../../aspose.pub/ipubpackageconverter/converttoformat/)(PackageDocumentCollection, bool, PubExportFormats, PubDocumentType) | Konvertiert jedes Dokument aus der *inputDocumentCollection*-Liste in das angegebene Format und speichert die Ergebnisse im entsprechenden Speicher. Der zu verwendende Speichertyp wird durch den Parameter *outputType* festgelegt. Verweise auf konvertierte Dokumente werden im zurückgegebenen [`PackageDocumentCollection`](../packagedocumentcollection/)‑Objekt abgelegt. Ist das Flag *mergeFiles* gesetzt, werden alle konvertierten Dokumente zu einem einzigen Dokument in derselben Reihenfolge zusammengeführt, in der sie in der *inputDocumentCollection*-Liste standen. |
