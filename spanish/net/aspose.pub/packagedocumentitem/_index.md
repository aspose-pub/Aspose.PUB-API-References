## PackageDocumentItem class

Clase base para referencias de documentos Publisher para su uso en conversiones de paquetes. Proporciona campos para especificar la fuente de salida del documento convertido - [`OutputFileName`](./outputfilename/) para un archivo en disco y [`OutputStream`](./outputstream/) para stream. También proporciona la configuración de conversión.
