## FontSubstitution.ReplaceAlways property

Especifica si las fuentes deben reemplazarse siempre. Si se establece en false, las fuentes se sustituyen solo cuando no se encuentra una fuente con el nombre especificado por el parámetro [`OriginalFontName`](../originalfontname/) en el PC de destino.

```csharp
public bool ReplaceAlways { get; }
```
