## SummaryInfo.DocSecurity property

El ID de seguridad del documento El ID de seguridad del documento es un entero con signo de 32 bits que representa un conjunto de banderas de control de acceso sugeridas por la aplicación con los siguientes valores: 0x00000001: Protegido con contraseña 0x00000002: Solo lectura recomendado 0x00000004: Solo lectura impuesto 0x00000008: Bloqueado para anotaciones
