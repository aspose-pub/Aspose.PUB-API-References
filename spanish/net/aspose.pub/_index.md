El espacio de nombres **Aspose.Pub** proporciona clases que describen objetos PUB.

## Clases

| Clase | Descripción |
| --- | --- |
| [BaseStyle](./basestyle/) | Declara la funcionalidad base para estilos PUB |
| [BuildVersionInfo](./buildversioninfo/) | Esta clase proporciona información sobre la compilación actual del producto. |
| [DocSummaryInfo](./docsummaryinfo/) | Información resumida del documento |
| [Document](./document/) | Representa un documento PUB, contiene todos los campos y valores relevantes |
| [FolderFontSource](./folderfontsource/) | Representa la carpeta que contiene los archivos de fuentes. |
| [FontSource](./fontsource/) | Representa una clase base para la fuente tipográfica. |
| [FontSubstitution](./fontsubstitution/) | Representa una clase para una estrategia de sustitución de fuentes basada en el nombre de la fuente. |
| [License](./license/) | Proporciona métodos para licenciar el componente. |
| [MetaInfo](./metainfo/) | Clase base para objetos de información resumida |
| [Metered](./metered/) | Proporciona métodos para establecer la clave medida. |
| [PackageDocumentCollection](./packagedocumentcollection/) | Representa una colección de documentos Publisher para la conversión de paquetes. |
| [PackageDocumentItem](./packagedocumentitem/) | Clase base para referencias de documentos Publisher para su uso en conversiones de paquetes. Proporciona campos para especificar la fuente de salida del documento convertido - [`OutputFileName`](../aspose.pub/packagedocumentitem/outputfilename/) para un archivo en disco y [`OutputStream`](../aspose.pub/packagedocumentitem/outputstream/) para flujo. También proporciona configuraciones de conversión. |
| [PackageFileItem](./packagefileitem/) | Diseñado para referenciar un documento Publisher mediante archivo en conversiones de paquetes. |
| [PackageStreamItem](./packagestreamitem/) | Diseñado para referenciar un documento Publisher mediante flujo en conversiones de paquetes. |
| [ParagraphStyle](./paragraphstyle/) | Esta clase describe el estilo del párrafo PUB |
| [PubFactory](./pubfactory/) | Fábrica para objetos PUB |
| [PubToPdfConversionOptions](./pubtopdfconversionoptions/) | Opciones para exportar al formato PDF |
| [SummaryInfo](./summaryinfo/) | Información resumida |
| [TextGroup](./textgroup/) | Grupo de texto |
| [TextParagraph](./textparagraph/) | Representa el párrafo de texto PUB |
| [TextStyle](./textstyle/) | Describe el estilo de texto PUB |
## Interfaces

| Interfaz | Descripción |
| --- | --- |
| [IPdfConverter](./ipdfconverter/) | Declara la funcionalidad para convertir un documento PUB en documento PDF |
| [IPubConverter](./ipubconverter/) | Declara la funcionalidad para convertir un documento PUB al formato especificado |
| [IPubPackageConverter](./ipubpackageconverter/) | Declara la funcionalidad para convertir varios documentos Publisher a un formato especificado. |
| [IPubParser](./ipubparser/) | Declara la funcionalidad que analiza el archivo publisher y devuelve el objeto [`Document`](../aspose.pub/document/) como resultado del análisis. |
