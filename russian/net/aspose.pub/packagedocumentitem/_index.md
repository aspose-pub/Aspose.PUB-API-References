## PackageDocumentItem class

Базовый класс для ссылок на документы Publisher, используемых в пакетных преобразованиях. Предоставляет поля для указания источника вывода преобразованного документа — [`OutputFileName`](./outputfilename/) для файловой системы и [`OutputStream`](./outputstream/) для потока. Также предоставляет настройки преобразования.
