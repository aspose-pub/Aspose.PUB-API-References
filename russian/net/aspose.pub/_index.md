Пространство имён **Aspose.Pub** предоставляет классы, описывающие объекты PUB.

## Классы

| Класс | Описание |
| --- | --- |
| [BaseStyle](./basestyle/) | Объявляет базовую функциональность для стилей PUB. |
| [BuildVersionInfo](./buildversioninfo/) | Этот класс предоставляет информацию о текущей сборке продукта. |
| [DocSummaryInfo](./docsummaryinfo/) | Сводная информация о документе |
| [Document](./document/) | Представляет документ PUB, содержит все поля и соответствующие значения. |
| [FolderFontSource](./folderfontsource/) | Представляет папку, содержащую файлы шрифтов. |
| [FontSource](./fontsource/) | Представляет базовый класс для источника шрифтов. |
| [FontSubstitution](./fontsubstitution/) | Представляет класс стратегии замены шрифтов, основанной на имени шрифта. |
| [License](./license/) | Предоставляет методы для лицензирования компонента. |
| [MetaInfo](./metainfo/) | Базовый класс для объектов сводной информации. |
| [Metered](./metered/) | Предоставляет методы для установки измеряемого ключа. |
| [PackageDocumentCollection](./packagedocumentcollection/) | Представляет коллекцию документов Publisher для пакетного преобразования. |
| [PackageDocumentItem](./packagedocumentitem/) | Базовый класс для ссылок на документы Publisher, используемых в пакетных преобразованиях. Предоставляет поля для указания источника вывода для преобразованного документа — [`OutputFileName`](../aspose.pub/packagedocumentitem/outputfilename/) для файловой системы и [`OutputStream`](../aspose.pub/packagedocumentitem/outputstream/) для потока. Также предоставляет настройки преобразования. |
| [PackageFileItem](./packagefileitem/) | Разработано для ссылки на документ Publisher через файл при конвертации пакетов. |
| [PackageStreamItem](./packagestreamitem/) | Разработано для ссылки на документ Publisher через поток при конвертации пакетов. |
| [ParagraphStyle](./paragraphstyle/) | Этот класс описывает стиль абзаца PUB |
| [PubFactory](./pubfactory/) | Фабрика объектов PUB |
| [PubToPdfConversionOptions](./pubtopdfconversionoptions/) | Параметры экспорта в формат PDF |
| [SummaryInfo](./summaryinfo/) | Сводная информация |
| [TextGroup](./textgroup/) | Группа текста |
| [TextParagraph](./textparagraph/) | Представляет текстовый абзац PUB |
| [TextStyle](./textstyle/) | Описывает стиль текста PUB |
