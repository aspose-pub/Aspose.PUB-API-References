## FontSubstitution constructor

Инициализирует новый экземпляр класса !:SimpleFontSubstitution.

```csharp
public FontSubstitution(string originalFontName, string substitutionFontName, 
    bool replaceAlways = false)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| originalFontName | String | Исходное имя шрифта. |
| substitutionFontName | String | Имя шрифта замены. |
| replaceAlways | Boolean | Указывает, следует ли всегда заменять шрифты. Если установлено в false, шрифты будут заменяться только когда шрифт с именем, указанным параметром [`OriginalFontName`](../originalfontname/), не найден на целевом ПК. По умолчанию false. |
