## FontSubstitution.ReplaceAlways property

Указывает, следует ли всегда заменять шрифты. Если установлено в false, шрифты заменяются только когда шрифт с именем, указанным параметром [`OriginalFontName`](../originalfontname/), не найден на целевом ПК.

```csharp
public bool ReplaceAlways { get; }
```
