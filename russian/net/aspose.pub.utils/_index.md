Пространство имён Aspose.PUB.Utils предоставляет вспомогательные объекты.

## Классы

| Класс | Описание |
| --- | --- |
| [Coord](./coord/) | Этот класс предназначен для представления данных, связанных с координатами полей PUB. Каждый поле в PUB содержит координаты, имеющие 2 пары координат: координаты верхнего левого угла (XLeft, YTop) и координаты нижнего правого угла(XRight, YBottom). Все координаты представлены в специальной метрической системе — English Metric Unit(EMUs). В класс были добавлены дополнительные методы для преобразования значений координат из английских метрических единиц в дюймы. |
